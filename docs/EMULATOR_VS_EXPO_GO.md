## 🎮 實際使用場景對比

### 場景 1: 添加快取項目

#### Android Studio 模擬器 ✅
```
1. 點擊「快取」標籤 → ✅ 正常
2. 點擊「+」按鈕 → ✅ 打開添加畫面
3. 輸入文字 → ✅ 正常
4. 選擇圖片 → ✅ 可以從模擬器相簿選擇
5. 添加關鍵字 → ✅ 正常
6. 點擊「儲存」 → ✅ 儲存到 WatermelonDB
7. 返回列表 → ✅ 看到新添加的項目
8. 重啟 App → ✅ 資料還在！
```

#### Expo Go ❌
```
1. 點擊「快取」標籤 → ✅ 正常
2. 點擊「+」按鈕 → ✅ 打開添加畫面
3. 輸入文字 → ✅ 正常
4. 選擇圖片 → ⚠️ 可能可以
5. 添加關鍵字 → ✅ 正常
6. 點擊「儲存」 → ❌ 報錯：Cannot read property 'initializeJSI'
7. 返回列表 → ❌ 看不到任何資料（資料庫無法工作）
8. 重啟 App → ❌ 所有資料消失
```

## 🔧 技術細節

### 為什麼 Expo Go 無法運作？

```typescript
// WatermelonDB 使用 JSI (JavaScript Interface)
// 這是一個 Native Module
import { Database } from '@nozbe/watermelondb'

// Expo Go 是預編譯的應用
// 不包含自定義 Native Modules
// 所以會報錯：initializeJSI of null
```

### Android Studio 模擬器為什麼可以？

```
Development Build = 
  您的代碼 + 
  所有 Native Modules（包括 WatermelonDB）+
  編譯為完整 APK

= 完整功能的應用
```
