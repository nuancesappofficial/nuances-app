# 📱 在 iPhone 上使用 Expo Go 快速預覽

## 🎯 當前狀態
Expo 開發伺服器正在啟動...

---

## 📋 接下來的步驟

### 1️⃣ 在 iPhone 上下載 Expo Go

打開 App Store，搜索並下載：**Expo Go**（免費）

### 2️⃣ 掃描 QR Code

Expo 啟動後，終端會顯示一個 QR code。

在 iPhone 上：
- 打開 Expo Go App
- 點擊「Scan QR Code」
- 掃描終端上的 QR code

### 3️⃣ 您會看到什麼

✅ **可以看到的**：
- 導航系統（快取/卡片兩個標籤）
- UI 界面設計
- 畫面切換動畫
- 空狀態提示

❌ **會報錯的部分**：
- 添加快取項目（嘗試寫入資料庫時）
- 查看卡片列表（讀取資料庫時）
- 錯誤訊息：`Cannot read property 'initializeJSI' of null`

---

## 💡 預期行為

### 啟動時
```
✅ Loading Nuances...
✅ 看到導航欄
✅ 顯示「快取」標籤
```

### 點擊「+」按鈕後
```
✅ 打開添加畫面
✅ 看到內容類型選擇器
⚠️ 儲存時會報錯（資料庫無法工作）
```

### 切換到「卡片」標籤
```
✅ 看到卡片列表畫面
❌ 但列表為空或報錯（無法從資料庫讀取）
```
