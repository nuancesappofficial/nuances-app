# API 整合後的功能增強路線圖

**日期：** 2026-02-11  
**目的：** 分析各 API 整合後會帶來的具體功能

---

## 📊 當前狀態（無 API）

### ✅ 已有的基礎功能

- 新增快取項目（手動輸入）
- 快取列表展示
- 手動創建卡片
- 基礎 Mock AI（20+ 詞庫）
- 卡片複習（SRS 演算法）
- 本地資料庫（WatermelonDB）

### ⚠️ 限制

- 無法自動分析陌生詞彙
- 定義質量有限（僅 20+ 詞）
- 無音標生成
- 無雲端備份
- 無跨設備同步
- 無圖片文字識別（OCR）
- 無圖片標註功能
- 無法從其他 App 分享

## 🤖 API #1: OpenAI GPT-4

### 已整合架構 ✅

**檔案：**
- `src/services/ai/openaiService.ts`
- `src/services/ai/index.ts`

### 🎯 會增加的功能

#### A. 智能文本分析

**當前（Mock）：**
```
文本: "The ephemeral beauty..."
↓
簡單長度過濾 → 提取 "ephemeral"
```

**整合後（OpenAI）：**
```
文本: "The ephemeral beauty..."
↓
GPT-4 語義分析 → 
- 理解上下文
- 識別關鍵概念
- 考慮難度等級
→ 提取 "ephemeral" + 解釋為什麼重要
```

**實際效果：**
- ✨ 更準確的關鍵詞選擇
- ✨ 理解俚語和片語
- ✨ 識別文化典故
- ✨ 適應不同文本類型（新聞、社交媒體、學術）

**當前（Mock）：**
```

↓

找到 → 返回預設定義
```

**整合後（OpenAI）：**

**實際效果：**
- ✨ 無限詞庫（不受限於 20+ 詞）
- ✨ 上下文特定定義
- ✨ 自動音標生成

- ✨ 學習目標導向（IELTS vs Casual vs Professional）

#### E. 學習目標個性化

**整合後新增：**

**IELTS 學習者：**
```
文本: "The government implemented stringent measures..."
↓
GPT-4 識別：
- stringent (Band 7 詞彙)
- implemented (Band 6 詞彙)
- measures (常用詞，跳過)
↓
優先推薦 "stringent"
標籤: IELTS, Band 7, Formal, Government
```

**Casual 學習者：**
```
文本: "I'm totally bummed about missing the concert."
↓
GPT-4 識別：
- bummed (美式俚語)
- concert (基礎詞，跳過)
↓
推薦 "bummed"
定義: 失望的；沮喪的 (disappointed, sad - informal)
解釋: 美式英語口語，常用於朋友間的非正式對話
標籤: Slang, American, Casual
```

**Professional 學習者：**
```
文本: "We need to optimize our ROI and streamline workflows."
↓
GPT-4 識別：
- optimize (商業常用)
- ROI (專業術語)
- streamline (商業動詞)
↓
推薦 "streamline"
解釋: 在商業情境中表示簡化流程、提高效率
標籤: Business, Management, Professional
```
