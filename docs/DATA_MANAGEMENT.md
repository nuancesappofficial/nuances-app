## 🔧 如何使用開發工具

### 方法 1：使用 UI（推薦）

1. **打開 App**
2. **切換到「🔧 工具」Tab**（底部第三個）
3. **查看數據統計**
   - 顯示當前數據量
   - Profiles / 快取項目 / 卡片 / 複習記錄

4. **清除數據（三個選項）**
   - **清除測試數據**：只刪除 test-user-001 和 demo-user
   - **清除所有數據**：⚠️ 刪除所有內容（不可撤銷）
   - **植入測試數據**：添加 4 個快取項目 + 5 張卡片

5. **點擊 🔄 刷新統計**

---

### 方法 2：使用代碼

**清除所有數據：**
```typescript
import { clearAllData } from './src/database/clearData';

// 在需要的地方調用
await clearAllData();
```

**只清除測試數據：**
```typescript
import { clearTestDataOnly } from './src/database/clearData';

// 清除 test-user-001 和 demo-user 的數據
await clearTestDataOnly();
```

**植入測試數據：**
```typescript
import { seedTestData } from './src/database/seedTestData';

// 添加測試數據
await seedTestData();
```

## 🎮 使用流程

### 場景 A：完全清除，從頭開始

1. 打開「工具」Tab
2. 點擊「清除所有數據」
3. 確認 → 完成
4. 開始真實使用：
   - 手動新增快取項目
   - 創建真實的學習卡片
   - 開始複習

### 場景 B：清除測試數據，保留自己的數據

3. 確認 → 完成

## 📝 常見問題

### Q: 為什麼看不到數據了？

**A:** 因為停用了自動測試數據植入。請：
- 方案 1：使用「工具」Tab 植入測試數據
- 方案 2：手動創建真實數據

---

### Q: 如何恢復測試數據？

**A:** 打開「工具」Tab → 點擊「植入測試數據」

---

### Q: 清除數據後能恢復嗎？

**A:** 不能！數據永久刪除。在正式使用前務必小心。

---

### Q: 「清除測試數據」會刪除我的數據嗎？

**A:** 不會！只刪除 user_id 為 `test-user-001` 或 `demo-user` 的數據。你手動創建的數據（其他 user_id）會保留。
