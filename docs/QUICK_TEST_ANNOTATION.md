# 快速測試圖片標註功能

## 🎯 測試目標
確認圖片標註功能正常運作，能看到標註區域的視覺反饋。

---

## 📱 測試步驟

### 1. 準備測試圖片
建議使用包含清晰文字的圖片，例如：
- 餐廳菜單
- 書本頁面
- 路標照片
- 任何包含英文或中文文字的圖片

### 2. 開啟 App 並上傳圖片

```
1. 點擊底部「快取」Tab
   ↓
2. 點擊右上角「+ 新增」
   ↓
3. 選擇「圖片/影片」類型
   ↓
4. 點擊「📷 從相簿選擇」
   （或點擊「📸 拍照」）
   ↓
5. 選擇一張測試圖片
```

**重要：** 圖片上傳後，應該會自動彈出「標註圖片」畫面

---

### 3. 測試標註工具

#### A. 檢查初始狀態
✅ 應該看到：
- 頂部工具列：「✏️ 開始標註」按鈕
- 中間：完整圖片顯示
- 底部：提示文字「點擊『開始標註』後...」
- **左下角（開發模式）：** 調試信息顯示容器尺寸

```
Container: 390x700  ← 應該顯示實際尺寸
Drawing: NO         ← 初始為 NO
```

#### B. 啟動標註模式
```
1. 點擊「✏️ 開始標註」
   ↓
2. 按鈕變成綠色：「✏️ 標註中」
   ↓
3. 調試信息顯示：Drawing: YES
   ↓
4. 底部提示變成：「💡 在圖片上拖動手指圈出關鍵區域」
```

#### C. 繪製標註框
```
1. 用手指在圖片上按住並拖動
   ↓
2. **拖動時** 應該看到：
   - 藍色虛線框跟隨手指移動
   - 框的大小隨拖動變化
   ↓
3. **放開手指後** 應該看到：
   - 虛線框消失
   - 出現綠色實線框（已完成的標註）
   - 框上方顯示「#1」標籤
   - 框右上角有紅色「✕」刪除按鈕
   - 工具列顯示「1 個標註」
   ↓
4. 繼續繪製第二個、第三個框
```

---

### 4. 檢查標註視覺效果

#### ✅ 正常情況應該看到：

**繪製中（藍色虛線框）：**
```
┌─ ─ ─ ─ ─ ─┐
│           │  ← 藍色虛線
│  拖動中   │  ← 半透明藍色背景
└─ ─ ─ ─ ─ ─┘
```

**完成後（綠色實線框）：**
```
┌─────────────┐
│ #1      [✕] │  ← 標籤 + 刪除按鈕
│             │  ← 綠色實線邊框
│  標註區域   │  ← 半透明綠色背景
└─────────────┘
```

#### ❌ 如果看不到標註框：

**問題排查：**

1. **檢查調試信息**
   - 左下角應該顯示容器尺寸
   - 如果顯示 `Container: 0x0`，表示布局未完成
   - 如果顯示 `Drawing: NO`，需要先點擊「開始標註」

2. **檢查 Console 日誌**
   打開 Chrome DevTools（Shift+M），查看是否有：
   ```
   [ImageAnnotation] Created box: {x: 0.2, y: 0.3, width: 0.4, height: 0.3}
   [ImageAnnotation] Total annotations: 1
   ```

3. **確認標註框大小**
   - 框太小會被忽略（< 2% 容器寬度/高度）
   - 嘗試繪製較大的框

4. **檢查圖片加載**
   - 圖片應該完整顯示
   - 如果圖片未加載，標註功能無法使用

---

### 5. 測試功能按鈕

#### A. 刪除單個標註
```
1. 點擊標註框右上角的紅色「✕」
   ↓
2. 彈出確認對話框
   ↓
3. 點擊「刪除」
   ↓
4. 標註框消失，計數減少
```

#### B. 清除全部標註
```
1. 當有多個標註時，工具列顯示「🗑️ 清除全部」
   ↓
2. 點擊後彈出確認
   ↓
3. 所有標註框清除
```

#### C. 完成標註
```
1. 點擊頂部「✓ 完成」
   ↓
2. 回到新增快取畫面
   ↓
3. 「標註關鍵區域」按鈕顯示標註數量
   例如：「✏️ 標註關鍵區域 (2)」
```

---

### 6. 保存並測試 OCR

```
1. 在新增快取畫面，填寫 Keywords（可選）
   ↓
2. 點擊「保存」
   ↓
3. 回到快取列表，找到剛才的項目
   ↓
4. 點擊項目，再點擊「創建卡片」
   ↓
5. **等待 OCR 處理：**
   - 顯示「🤖 OpenAI GPT-4 分析中...」
   - 自動提取標註區域的文字
   - 生成定義、音標、標籤
   ↓
6. 檢查生成的內容是否正確
```

## 🐛 常見問題

### Q1: 看不到藍色虛線框
**A:** 
- 確認已點擊「✏️ 開始標註」（按鈕應該是綠色）
- 檢查調試信息：`Drawing: YES`
- 嘗試用力按壓並拖動（不要只是點擊）

### Q2: 放開手指後沒有綠色框
**A:**
- 框可能太小被忽略了，畫大一點
- 檢查 Console 是否有 `Box too small, ignored` 日誌
- 確認容器尺寸不為 0

### Q3: 標註工具沒有彈出
**A:**
- 檢查圖片是否成功上傳（`selectedImage` 不為空）
- 手動點擊圖片上的「✏️ 標註關鍵區域」按鈕
- 重新選擇圖片

### Q4: OCR 識別失敗
**A:**
- 確認 `.env` 文件包含 `EXPO_PUBLIC_OPENAI_API_KEY`
- 檢查網絡連接
- 確認標註區域包含清晰的文字
- 查看 Console 錯誤信息
