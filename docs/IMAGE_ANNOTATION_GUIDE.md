## 🧪 測試步驟

### 場景 1：餐廳菜單學習

**目標：** 拍攝菜單，學習食物名稱

```
1. 打開 App
   ↓
2. 點擊「快取」Tab → 「+ 新增」
   ↓
3. 選擇「圖片/影片」
   ↓
4. 點擊「📸 拍照」或「📷 從相簿選擇」
   （選擇一張包含菜單的圖片）
   ↓
5. 圖片上傳後，自動彈出標註工具
   ↓
6. 點擊「✏️ 開始標註」
   ↓
7. 用手指拖動，在菜名上畫框
   （例如：Bruschetta, Caesar Salad）
   ↓
8. 標註完成後，點擊「完成」
   ↓
9. 點擊「保存」
   ↓
10. 回到快取列表，點擊剛才的項目
    ↓
11. 點擊「創建卡片」按鈕
    ↓
12. AI 自動：
    - OCR 提取標註區域的文字
    - 分析並生成定義
    - 提供音標和標籤
    ↓
13. 檢查生成的內容，點擊「保存」
```

**預期結果：**
- ✅ 成功識別菜名（如 "Bruschetta"）
- ✅ 生成定義：「義大利開胃菜，烤麵包配番茄」
- ✅ 音標：`/bruːˈsket.ə/`
- ✅ 標籤：Food, Italian, Casual

## ❌ 常見問題排查

### 問題 1：標註工具無法打開
**症狀：** 點擊「標註關鍵區域」按鈕無反應

**解決方案：**
- 確認圖片已成功上傳（`selectedImage` 不為空）
- 檢查控制台是否有錯誤訊息

---

### 問題 2：OCR 識別不到文字
**症狀：** 顯示「未識別到文字」

**可能原因：**
- 圖片模糊或解析度過低
- 標註區域太小
- 圖片中無可識別文字

**解決方案：**
- 重新拍攝清晰照片
- 擴大標註區域
- 確認標註區域包含文字內容

---

### 問題 3：AI 分析失敗
**症狀：** 顯示「分析失敗」或使用 Mock AI

**可能原因：**
- OpenAI API Key 未配置或無效
- 網絡連接問題
- API 配額用盡

**解決方案：**
```bash
# 1. 檢查 API Key
cat .env | grep OPENAI

# 2. 測試網絡連接
curl https://api.openai.com/v1/models -H "Authorization: Bearer YOUR_API_KEY"

# 3. 查看 OpenAI 使用情況
# https://platform.openai.com/usage
```

---

### 問題 4：圖片顯示異常
**症狀：** 圖片無法顯示或模糊

**解決方案：**
- 確認 `imageStoragePath` 正確保存
- 檢查圖片 URI 格式
- 測試使用本地測試圖片
