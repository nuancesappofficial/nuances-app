# Android Release Readiness Checklist

## Repository-complete items

- Android Sharesheet intent filters are generated by `plugins/withAndroidShareIntent.js`; payload handling lives in the `android-share-intent` local Expo module.
- Android OCR uses bundled ML Kit Text Recognition from the `vision-ocr` local Expo module.
- EAS production builds an AAB, uses remote EAS-managed credentials, and auto-increments the remote Android `versionCode`.
- Production disables subscription development bypass and internal tester tools.
- RevenueCat selects the Apple or Google public SDK key by platform and keeps entitlement ID `premium`; a missing platform key fails closed.
- Apple Sign-In is shown only on iOS. Android uses Google Sign-In and requires environment-provided OAuth IDs.
- Legacy Android storage and overlay permissions are blocked. Camera, microphone, and notifications remain because the app uses camera OCR, pronunciation recording, and study reminders.
- Keystores, passwords, Google service-account JSON, and other private credentials must never be committed.

## Do not upload

`android/app/build/outputs/bundle/release/app-release.aab` produced by the generated local Gradle project uses the template debug signing configuration unless a proper release credential is injected. Do not upload this artifact. Produce the publishable artifact with an EAS production build using the EAS-managed Android upload key, then verify its signer certificate.

## Manual blockers in Google / RevenueCat consoles

- Confirm or create the Google Play Console account and app for package `com.jeffenglishlearning.nuances`.
- Complete Play App Signing and obtain the actual upload/app-signing SHA-1 and SHA-256 fingerprints.
- Create/configure the Google Android OAuth client for this exact package and fingerprints; provide `EXPO_PUBLIC_GOOGLE_ANDROID_CLIENT_ID` and the Web OAuth client ID.
- Create/configure the RevenueCat Google Play app and provide `EXPO_PUBLIC_REVENUECAT_GOOGLE_API_KEY` (public SDK key).
- Create Google Play subscription products and map their exact product IDs to the RevenueCat `premium` entitlement/current offering.
- Provide Google Play service credentials to RevenueCat and, if automated submission is desired, an appropriately scoped Play service account to EAS Submit.
- Complete Play Console declarations, Data safety, content rating, target audience, store listing, pricing/countries, testing track, and reviewer access instructions.
- Run an EAS production build, download its AAB, verify it is not signed by `CN=Android Debug`, and only then upload or submit it.

Run `npm run check:android-release` before every Android release candidate. `MANUAL` means external console/account data is still required; `WARN` must be reviewed; any `FAIL` blocks release.
