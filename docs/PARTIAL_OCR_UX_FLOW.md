# 圖片部分文字識別 - 完整 UX 流程

## 🎯 功能目標

讓用戶可以：
1. 上傳圖片（例如 IELTS 題目、書本頁面）
2. 用手指圈選想要學習的特定單字或短語
3. 系統自動識別圈選區域的文字
4. 快速創建學習卡片

---

```
用戶操作流程：
1. 用手指在 "walking" 上按住
2. 拖動形成矩形框
3. 釋放手指
4. 看到藍色虛線框（視覺反饋）
5. 1-2 秒後，頂部藍色面板顯示「📝 識別結果：walking」

關鍵視覺反饋：
✅ 拖動時：半透明藍色框跟隨手指
✅ 釋放後：藍色虛線框固定
✅ OCR 處理中：「🔍 識別圈選區域中...」
✅ OCR 完成：「📝 識別結果：walking」
```

**用戶心智模型**：
- "我要圈出 'walking' 這個字"
- "拖動手指形成框"
- "看到藍色框，表示圈選成功"
- "等待系統識別文字"
- "看到識別結果，確認正確"

**如果識別錯誤**：
- 點擊 「🗑️ 清除全部」
- 重新圈選

### 階段 6：創建卡片

```
┌─────────────────────────────────────┐
│  📇 Create Card                     │
│                                     │
│  🔍 分析中...                        │ ← 正在分析
│  ┌─────────────────────────────┐   │
│  │ 使用 OpenAI API 分析文字內容   │   │
│  └─────────────────────────────┘   │
│                                     │
│  原始內容預覽                         │
│  ┌─────────────────────────────┐   │
│  │ [圖片預覽]                    │   │ ← 顯示來源圖片
│  │         ✏️ 1 個標註           │   │
│  └─────────────────────────────┘   │
│                                     │
│  識別文字：walking                   │
└─────────────────────────────────────┘

處理流程：
1. 讀取 imageStoragePath
2. 解析 imageAnnotations（JSON 字符串）
3. 調用 extractTextFromAnnotations
4. OCR 識別圈選區域的文字：「walking」
5. 將「walking」發送給 OpenAI 分析
6. 生成定義、音標、例句等

幾秒後 ↓
```

## 🎯 關鍵 UX 設計原則

### 1. **即時反饋**
- ✅ 拖動時顯示半透明框
- ✅ 釋放後顯示固定的虛線框
- ✅ OCR 處理中顯示「🔍 識別中...」
- ✅ 完成後立即顯示結果

### 2. **視覺引導**
- ✅ 按鈕清晰（「✏️ 開始標註」）
- ✅ 狀態明確（「✏️ 標註中」vs「✏️ 開始標註」）
- ✅ 顏色編碼（藍色 = OCR 相關）

### 3. **容錯設計**
- ✅ 可以清除標註重新圈選
- ✅ OCR 失敗時自動 fallback
- ✅ 可以手動編輯 Keywords

### 4. **情境保留**
- ✅ 快取列表顯示圖片預覽
- ✅ 卡片列表顯示來源圖片
- ✅ 標註數量徽章

## 🧪 完整測試流程

### 測試案例 1：IELTS Writing Task

**目標**：圈選題目中的單一關鍵詞

1. **準備圖片**：IELTS Writing Task 2 題目截圖
2. **選擇圖片**：點擊「📸 選擇圖片」
3. **開始標註**：點擊「✏️ 開始標註」
4. **圈選單字**：圈選 "measures" 或 "effective"
5. **驗證 OCR**：
   - ✅ 看到藍色虛線框
   - ✅ 頂部顯示「📝 識別結果：measures」
   - ✅ 不應該識別到整張圖的所有文字
6. **完成標註**：點擊「完成標註」
7. **驗證自動填入**：
   - ✅ Keywords 欄位自動填入「measures」
   - ✅ 藍色提示：「💡 圖片識別：measures」
8. **保存快取**：點擊「💾 儲存到快取」
9. **驗證快取列表**：
   - ✅ 顯示圖片預覽
   - ✅ 顯示「✏️ 1 個標註」
   - ✅ 關鍵詞：measures
10. **創建卡片**：點擊「📇 創建卡片」
11. **驗證分析**：
    - ✅ 顯示「🔍 分析中...」
    - ✅ 顯示圖片預覽
    - ✅ 顯示「識別文字：measures」
12. **驗證結果**：
    - ✅ 目標單字：measures
    - ✅ 定義準確
    - ✅ 原句包含 measures
13. **保存卡片**
14. **驗證卡片列表**：
    - ✅ 顯示圖片預覽
    - ✅ 單字和定義正確

---

## 🔄 可能的改進方向

### 短期改進（1-2 週）

1. **增強 OCR 提示**
   - 當 OCR 識別中時，顯示進度動畫
   - 識別失敗時，提供友好的錯誤訊息和重試按鈕

2. **標註預覽優化**
   - 在標註模式中，允許長按框框來刪除單一標註
   - 顯示每個標註的序號（1, 2, 3...）

3. **引導教學**
   - 首次使用時，顯示簡短的教學動畫
   - "第一次標註？拖動手指圈選你想學的單字"

---

### 中期改進（1-2 月）

1. **圖片裁剪方案**
   - 重新構建 Development Build
   - 啟用真正的圖片裁剪（100% 精確）
   - 混合方案：有裁剪時用裁剪，無裁剪時用智能 Prompt

2. **多標註支持**
   - 允許在一張圖片上圈選多個單字
   - 批量識別並創建多張卡片

3. **OCR 結果編輯**
   - 如果 OCR 識別錯誤，允許手動修正
   - 顯示置信度分數

---

### 長期改進（3-6 月）

1. **離線 OCR**
   - 整合 Google ML Kit 或其他離線 OCR
   - 無需網絡也能識別

2. **智能推薦**
   - 根據圖片內容推薦難度等級
   - 自動檢測是 IELTS、托福還是日常英語

3. **協作標註**
   - 分享圖片和標註給朋友
   - 協作學習
