## Description

Nuances helps English learners capture useful language from daily life and turn it into practical flashcards for review.

Create cards from typed text, images, documents, or shared content. Organize cards into albums, review them with lightweight study tools, and use pronunciation support when you want focused speaking practice.

Premium features unlock AI-assisted card generation, cloud text-to-speech voices, pronunciation scoring, and expanded learning workflows. Purchases and restore purchases are handled through Apple in-app purchase.

Key features:
- Create flashcards from text, images, and shared content
- Organize learning material with albums and favorites
- Review cards with examples, pronunciation, and saved context
- Generate AI-assisted cards through secure backend functions
- Practice pronunciation with microphone-based scoring
- Use cloud text-to-speech for natural playback
- Import content from other apps using the iOS share extension

Nuances is designed for learners who want to build a personal English memory bank from the words, phrases, and examples they actually encounter.

## App Review Notes

Nuances helps users create and review language-learning flashcards. Reviewers should sign in with Apple, complete onboarding if prompted, and test card creation from typed text, images, or shared content.

Premium features are sold through Apple in-app purchase via RevenueCat. The membership screen displays the active RevenueCat offering, supports purchase, and includes Restore Purchases. The submitted subscription products are Weekly Premium, Monthly Premium, and Yearly Premium.

AI card generation, cloud text-to-speech, and pronunciation scoring are routed through Supabase Edge Functions so provider secrets are not included in the app bundle. Pronunciation scoring uses microphone access only after the user starts the pronunciation practice flow.

The iOS share extension lets users send text or images into Nuances through the configured App Group. Account deletion is available in Settings and deletes the authenticated user's Supabase auth account, profile, cards, cached items, media, review history, sync metadata, and subscription records.

No separate demo username or password is provided. Please use Sign in with Apple for review testing.
